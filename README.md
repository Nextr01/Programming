# Programming

A structured collection of code snippets, practice exercises, and mini-projects as I learn programming from basics to advanced concepts.

## Folder Structure

```text
Programming/
├── README.md
├── c/
│   ├── 01-basics/
│   ├── 02-control-flow/
│   ├── 03-arrays-and-pointers/
│   └── 04-data-structures/
├── sql/
│   └── queries_and_joins/
└── other-languages/
```

## Languages & Topics

* **C (`c/`):** Fundamentals, loops and conditionals, arrays, pointers, functions, structures, file handling, and data structures.
* **SQL (`sql/`):** Queries, filtering, joins, aggregations, and relational database practice.
* **Additional Languages:** New language folders will be added as I explore more tools and paradigms.

## How Code Is Organized

* Folder names use lowercase letters and hyphens (for example, `01-basics`, `03-arrays-and-pointers`) to keep progression clear.
* File names use `snake_case` (for example, `hello_world.c`, `pointer_basics.c`) and describe what the program demonstrates.

## Compiling & Running C Programs

Using `gcc` in a terminal:

```bash
gcc c/01-basics/hello_world.c -o hello_world
./hello_world
```

*(On Windows, run `hello_world.exe` instead of `./hello_world`.)*
